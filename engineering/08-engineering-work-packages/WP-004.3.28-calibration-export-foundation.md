# WP-004.3.28 — Calibration Export Foundation

Status: deterministic reconstruction foundation implemented; EXPORT remains blocked pending qualified checksum/integrity authority.

The original subscriber Current binary remains immutable. Reconstruction operates on a copy and requires an exact Current Dataset, Working Calibration, ROM-layout relationship and Definition Set binding. A Raw Mutation Plan records every changed cell, affine inverse, raw target, address, representation, byte range and source-byte precondition. Non-representable targets, quarantine, mismatched bindings, address failures and conflicting writes fail closed. Identical canonical overlapping writes are permitted; different bytes at the same offset are rejected.

Reconstruction changes only plan-authorized bytes, emits deterministic changed ranges and identities, proves zero unexplained byte changes, and requires a caller-supplied post-reconstruction container/membership validator. It does not mutate the source object and does not describe output as flashable.

Repository discovery found no qualified BMW checksum algorithm, checksum region, integrity-field mutation strategy, or authoritative external-flasher correction contract. Database checksum metadata is descriptive and does not grant authority. Therefore all 68 active relationships are `EXPORT_BLOCKED_CHECKSUM_UNKNOWN`; none is `EXPORT_QUALIFIED` or `FLASH_QUALIFIED`.

The BMW-wide technical census classifies 74,165 EDIT-qualified Tables as reconstruction-plan capable, with 51 blocked by non-invertible conversion and four blocked by quarantine. All 68 relationships contain at least one reconstruction-qualified Table, but relationship-level complete export is not inferred from Table counts.

Durable derived subscriber sessions intentionally do not contain the private original BIN. The transient raw-upload object is deleted after provider processing. A later deliberate Build/Export operation therefore requires a separately authorized, private, encrypted-at-rest, owner/vehicle/session-bound source-binary retention lease with opaque keys, bounded TTL, explicit deletion, and no public URL. This foundation does not extend raw BIN retention or expose UI controls.
