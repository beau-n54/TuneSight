# WP-004.3.12 — Governed Modified-Binary ROM-Layout Membership

## Authority derivation

Definition Set applicability remains the Founder-accepted Definition Set Revision ↔ ROM Layout relationship. A new exact binary receives separate subordinate membership authority derived from that active relationship, deterministic Evidence, and the Founder-approved membership contract. It does not create or revise Definition applicability and does not mutate the historical relationship.

## Exact identity and Evidence threshold

The immutable candidate identity binds SHA-256, extracted byte length, container resolution, internal observations, source role, and provenance; filename remains metadata. Evidence binds the candidate digest, target layout, active relationship, Definition Set, expected and observed marker multiplicity/offsets, credible identifiers, Definition-compatible address range, complete structural extraction validation, contradictions, limitations, and contract revision.

Automatic `qualified_member` is allowed only when exact bytes match their identity; container and length match; every expected marker preserves exact multiplicity and offsets; exactly one credible expected ROM identity is present; no credible contradictory identity exists; the complete address range is present; the active relationship and Definition Set match; and every extraction-capable Definition succeeds with scalar, 1D, and 2D coverage. Exact reference digest, checksum equality, calibration-value equality, and percent-bytes-same are not authority.

## Outcomes and review boundary

Outcomes are `qualified_member`, `more_evidence_required`, `technical_conflict`, `unknown_layout`, and `invalid_binary`. Complete deterministic Evidence may qualify automatically under the approved contract, avoiding per-upload Founder review. Incomplete or multi-credible-marker Evidence requires review; contradictions fail closed. Future MG1 ambiguity is preserved rather than resolved by selecting one marker.

## Domain separation and integration

Membership is not Stock Variant Knowledge. Source roles such as modified, MapSwitch, or user tune make no authenticity, correctness, safety, meaning, or recommendation claim. Qualified extraction and comparison accept either historical subordinate Evidence or a verified new membership record. Raw and engineering Evidence bind the new digest. Broad layout discovery, upload/runtime wiring, persistence, Supabase, semantics, Suggested Calibration, Workshop UI, editing, Native Vehicle Data, WP-005.1, and flashing remain excluded.

Completion requires all four real Original/MapSwitch positives without using their historical digest admission, in-memory light/heavy calibration modifications, wrong-ROM/marker/contradiction/truncation negatives, ambiguity and unknown outcomes, extraction/conversion/comparison compatibility, full regressions, and one clean local commit without push.
