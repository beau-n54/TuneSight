# WP-004.3.11 — Qualified Calibration Comparison

## Authority and terminology

A comparison requires two exact binaries independently admitted beneath one active qualified ROM-layout relationship and the same exact Definition Set Revision. The complete qualified Definition universe is processed. Current N54 originals remain `stock_candidate` references because Stock Variant authority is `exact_candidate`, not `exact_verified`. MapSwitch is a source role only; it is not a safety, quality, recommendation, or user-current-tune claim.

## Identity and outcomes

The immutable request binds both directional exact binary identities and bytes, roles/provenance, ROM layout, active relationship, Definition Set, registry snapshot, and contract. Direction is identity-bearing. Identical digests produce an explicit deterministic `identical_inputs` result.

Each Definition is `unchanged`, `changed`, `axis_changed`, `value_and_axis_changed`, `comparison_unavailable`, or `representation_conflict`. No unavailable or conflicted Definition is omitted. Qualified raw extraction and safe engineering conversion run independently for both sides before comparison.

## Cells, deltas, regions, and axes

Exact deterministic finite engineering-number equality uses JavaScript numeric `===`; there is no hidden epsilon or UI tolerance. Changed cells preserve coordinates, both raw offsets and values, both engineering values, signed `modified - reference` delta, absolute magnitude, units, equation revision, and percentage outcome. Percentage is unavailable when the reference is zero and never returns Infinity.

Complete engineering Evidence remains attached while changed-cell summaries stay sparse. Summaries preserve totals, changed percentage, signed extrema, maximum magnitude, affected rows/columns, and axis state. Changed regions are bounded four-neighbour geometric components with coordinate bounding rectangles; they carry no operating-region semantics. Axes are compared separately with their values, units, equation identity, positions, and signed deltas.

## Evidence and boundaries

Qualified Comparison Evidence preserves both exact digests and roles, ROM layout, relationship, Definition Set, registry snapshot, every per-Definition result, cohort totals, findings, identity/revision, and provenance inherited through both engineering Evidence chains. It answers only what changed.

The model is suitable for a future reference/current table browser, changed-only filtering, cell highlighting, deltas, regions, axes, and metadata. Calibration Knowledge binding, significance, recommendations, TuneSight Suggested, editing, reconstruction, export, UI/runtime wiring, Supabase, Native Vehicle Data, WP-005.1, and flashing are excluded. Arbitrary modified binaries still require governed binary-to-layout qualification.

Completion requires deterministic complete comparisons for all four admitted current N54 sets, wrong-ROM and Legacy rejection, identical-input proof, real changed and unchanged tables, scalar/1D/2D and axis tests, full regressions, and one clean local commit without push.
