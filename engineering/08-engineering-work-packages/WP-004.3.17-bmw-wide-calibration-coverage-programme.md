## AA. Education coverage

BMW-wide completion for a qualified Table means evidence-backed coverage of: what it is and controls; why it exists; how to read it; axis and value meanings; contextual increase/decrease behavior; operating context; related Tables; telemetry; limitations; and advanced engineering Evidence. Terminology is invariant: Definition = governed domain identity; Calibration Table = one user-facing function; Calibration = complete calibrated dataset; Map/Tune = completed calibration intended for or used in flashing.

## AD. Scalable admission strategy

Process cohorts, not isolated files: generate deterministic Evidence packages for every repeated naming/layout pattern; group identical passing Evidence; isolate exceptions; review only ambiguous or authoritative claims; publish exact relationships through the existing deterministic registry; run membership, conversion, Dataset, comparison, and wrong-ROM-negative suites; then expose only qualified identities to the provider.

## AE. Future-platform extensibility

The XDF interpreter, extraction/conversion contracts, qualified Dataset/comparison, view model, visualizations, and Knowledge binder are registry/data driven. A new representable platform should require records and Evidence, not a new component branch. The current exception is the development provider's N54 vocabulary, N54 path/registry imports, and IJE0S selection/label. Replacing that boundary with a qualified registry lookup is required before adding platforms without code changes.

## AF. Workshop-ready definition

A ROM/layout is **Calibration Workshop Ready** when it has a qualified ROM layout and Definition Set; exact binary discovery/membership; successful engineering conversion and Dataset materialisation; structural Table Information; generic rendering; and truthful unavailable/error states. **Comparison Ready** additionally requires a responsible Reference and current/modified binary. **Knowledge Complete** is a stronger, independently measured state. None implies editing, Suggested Calibration, Map generation, or flash safety.

Record `domain validated` and `physically validated` independently; physical access is not required for structural admission.
