# WP-004.3.30 — N54 and B58 Gen1 Checksum Qualification

## Task A — N54 MSD80 / MSD81 conclusion

The four active N54 relationships use 2,097,152-byte controlled BIN images. Repository authority distinguishes I8A0S as MSD80 and IJE0S, IKM0S and INA0S as MSD81.

External evidence establishes that checksum handling exists: BitBox documents read/write/checksum support for Continental MSD8x TC1796 2 MiB images; the inspectable 8HP patch project requires a separate MSD8x checksum tool after MSD80/MSD81 modification; and an MSD81 code project names one program-area checksum-related location but delegates calculation to a closed executable. None discloses a complete calibration checksum algorithm, regions, stored fields, byte order/parameters, or reproducible known-valid/corrupt/repaired vectors. It therefore cannot establish that MSD80 and MSD81 share an algorithm or qualify either adapter.

Official MHD custom-tune documentation establishes a selectable `.bin`/`.mhd` workflow but does not state whether checksums are pre-required, validated, repaired or container-wrapped. It is workflow evidence only.

Task A result: MSD80 `CHECKSUM_UNKNOWN`; MSD81 `CHECKSUM_UNKNOWN`; no adapter; no controlled checksum vectors; zero N54 EXPORT-qualified relationships.
