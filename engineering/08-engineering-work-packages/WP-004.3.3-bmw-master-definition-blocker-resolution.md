# WP-004.3.3 — BMW Master Definition Blocker Resolution

**Status:** Implementation Slice — Founder Authorised

## Purpose

This slice resolves generic structural blockers identified by complete BMW master-library traversal without converting coverage into applicability or semantic authority.

## Datatype Semantics

Datatype resolution preserves both the resolved kind and its source. An axis may be an explicit integer (`datatype=0`), inherit integer representation from an explicit header default (`DEFAULTS float=0`), remain unsupported, or remain unresolved. Width alone never establishes datatype.

The current 99-file library contains only explicit datatype `0`; every header explicitly declares `float=0`. Inherited integer resolution is therefore source-governed rather than a coverage-driven guess.

## Definition Identity

Stable Definition identity uses definition kind, primary address and deterministic storage layout. Storage layout includes axis role, address, dimensions, width, strides, type flags and resolved datatype kind. Datatype derivation provenance remains in the Definition Revision but does not split otherwise equivalent identities. Display titles and source ordering remain excluded.

Exact structural duplicates are preserved as aliases of the same stable identity. Different layouts sharing a primary address receive distinct identities. Definitions sharing the same storage layout but declaring materially different representations remain explicit conflicts.

## Source Lexical Resolution

The parser accepts decimal, `0x`-prefixed hexadecimal and unprefixed hexadecimal containing hexadecimal alphabetic digits. This generic lexical rule resolves the one previously invalid source, whose four addresses use deterministic unprefixed hexadecimal notation. Filename-specific handling is prohibited.

## Axis Representation

Axes are classified as address-backed, static literal, calculated, externally referenced or unresolved. Address-backed axes may produce raw binary values. Static literal labels are preserved separately and never represented as binary reads. Calculated axes remain inert; equations are not executed. External and unresolved axes remain explicit.

## Coverage Progression

Baseline: 99 files, 98 structurally readable, 1 invalid, 104,239 definitions, 47,878 extraction-capable and 56,361 blocked.

After blocker resolution: 99 files structurally readable, 105,335 definitions, 105,202 extraction-capable and 133 blocked by unresolved representation conflicts. The additional 1,096 definitions come from structurally interpreting the formerly invalid source. Exact aliases remain visible and do not manufacture new semantic authority.
