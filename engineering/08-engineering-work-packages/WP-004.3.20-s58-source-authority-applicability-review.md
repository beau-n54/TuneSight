## Exact-scope authority architecture

`tunesight.xdf-source-authority-record.v1` can represent an existing accepted pathway—explicit source authority, governed Evidence review, or authoritative Stock Variant relationship—without inventing an S58-specific class. Identity binds authority class, reviewed lineage, and an explicit set of exact Source Artifact IDs/digests, Definition Set IDs/revisions, and family scopes. Revision additionally binds provenance and limitations.

Scope evaluation requires an exact complete binding. Changed digests, corrected/future Definition Set revisions, unlisted S58 artifacts, B58 artifacts, and another family fail closed. One reviewed authority record may cover several explicitly enumerated sources, but every exact applicability relationship still requires its own proposal, assessment, decision, and publication. A changed authority revision deterministically changes downstream review input and requires reassessment; it does not rewrite unaffected relationships.
