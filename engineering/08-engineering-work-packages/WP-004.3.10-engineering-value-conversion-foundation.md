# WP-004.3.10 — Engineering-Value Conversion Foundation

## Authority and purpose

This bounded slice consumes immutable Qualified Raw Calibration Value Evidence and its existing exact-binary, ROM-layout, applicability-relationship, Definition Set, and Definition Revision provenance. It adds deterministic numerical representation Evidence; it does not create applicability, Calibration Knowledge, recommendations, edits, or runtime authority.

## Equation census and semantics

The deterministic census covers all 99 BMW master-library XDF files and 105,335 Definitions. Every Definition has an equation-bearing axis: 216,243 occurrences and 272 unique sources. Declared variables are `X` (216,114 occurrences) and lowercase `x` (129), both denoting the already decoded signed/unsigned integer supplied by raw extraction. The language uses decimal literals, unary signs, `+`, `-`, `*`, `/`, and parentheses. No functions, exponentiation, bitwise operations, conditionals, lookups, multiple expressions, or inverse/reverse equation attributes occur. Datatype, width, signedness, byte order, and address translation are resolved before conversion by raw extraction; equations operate afterward on each decoded number.

## Safe grammar and evaluator

Equation source is tokenized, parsed into an explicit immutable AST, validated, canonically serialized, and evaluated without `eval`, `Function`, VM execution, property access, assignments, functions, or dynamic invocation. Limits are 256 source characters, 128 tokens, depth 16, literal magnitude `1e100`, and finite result magnitude `1e300`. Division by zero and non-finite/out-of-range results are explicit failures.

Whitespace and `X`/`x` case normalize only after successful parsing. Canonical AST identity determines equation identity/revision. Parentheses and operator precedence are represented structurally; material semantic changes change identity.

## Engineering Value Evidence

The conversion request binds the exact Qualified Raw Evidence, canonical Definition Revision, equation source, units source, and conversion contract. Successful immutable Evidence preserves the raw Evidence identity/revision, exact binary digest, ROM layout, full applicability authority chain, Definition Set and Definition revisions, equation source and identity, raw and engineering values, dimensions, per-cell row/column/offset trace, axis conversions, units, findings, and provenance.

Units remain source metadata; no physical-unit inference or cross-unit conversion occurs. Axis conversion is independent from value-cell conversion. Static literals remain literal evidence. Missing, unsupported, malformed, or numerically invalid equations never silently relabel raw values as engineering values.

## Boundaries and completion

No inverse equations exist in the current master library. Reverse byte writing is excluded. The 133 representation-conflicted Definitions remain ineligible even when an individual expression parses. Legacy applicability, arbitrary modified-binary qualification, Stock/Modified comparison, semantic Knowledge, safety judgements, recommendations, Workshop, UI, API, persistence, Supabase, Native Vehicle Data, WP-005.1, and flashing are excluded.

Completion requires exact master-library census coverage, hostile parser tests, independent arithmetic expectations, scalar/1D/2D and axis preservation, four current governed N54 proofs, regression validation, and a clean local commit without push.
